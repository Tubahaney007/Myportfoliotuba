# Tuba Haney | Data Science Portfolio

A static portfolio built with HTML, CSS, and vanilla JavaScript. No package installation or build step is required.

## Preview locally

Open `index.html` in a browser, or serve this folder with any local static file server.

## Publish with GitHub Pages

1. Push this project to a GitHub repository on the `main` branch.
2. In the repository, open **Settings → Pages** and select **GitHub Actions** as the deployment source.
3. Push to `main` (or run **Deploy portfolio to GitHub Pages** from the Actions tab). The workflow publishes the site.
4. GitHub displays the published URL in the Pages settings and the deployment run.

The project is kept at the repository root so the static Pages workflow can publish it directly. Images and the video are in `assets/`.

## Personalize before publishing

- Replace `assets/video/video-resume.mp4` with the video you want to publish, or update the video source in `index.html` to a hosted file.
- Fill in the bracketed project-role and NPTEL course details in `index.html` when ready.
- The contact form opens a prefilled email in the visitor's default email app; it does not send or store form submissions on a server.
- Review the public contact details and supplied links before publishing.
